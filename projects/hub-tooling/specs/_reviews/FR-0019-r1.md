## FINDINGS

1. **BOM before the opening fence leaks the block silently.** A UTF-8 BOM means the source does not start with `---`, so AC-3's no-block fallback applies. The wrapper gets `Run the <name> command.`, and the whole block appears in both wrapper bodies with no warning. This conforms to the AC's letter. Suggest stripping `﻿` or warning, in a later FR (FR-0020 or FR-0022). Pinned as observed by `test_bom_before_the_fence_falls_back_and_leaks_the_block`.
2. **Empty block: right outcome, wrong cause text.** For `---\n---\n`, `_split_command_source` searches for `\n---\n` from offset 4, so a fence right after the opener is never matched. The warn says "no closing '---' found". If the body later contains a `---` rule, the warn says "not a mapping" instead. Refusal is correct either way; only the message misleads.
3. **Folded continuation lines pass AC-5.** `description: a\n  b` parses to the single-line string `"a b"`, so AC-5 does not fire, although AC-2's shape is one `key: value` line per key. It is harmless because the rendering is still one line, but the source shape is not enforced. Pinned by `test_folded_continuation_line_is_accepted_as_one_line`.
4. **A block closed at end of file with no trailing newline** (`---\n…\n---`) is refused as "no closing". This only matters for a body-less source, so it is acceptable.
5. **The first rewrite of any committed-CRLF IDEA or PATTERN file will be a whole-file diff** (the file is normalised to LF) until the Orchestrator's post-merge `chore(hub): normalise line endings (FR-0019)` lands. Land the chore promptly after merge.
6. **Pre-existing, not FR-0019:** the first `--upgrade --yes` on a fresh `--stack python` project reverts `.cursor/rules/20-python.mdc` and `.github/workflows/agent-gates.yml` to their template (disabled or commented) form, undoing `enable_cursor_rule` and `uncomment_ci_job`. The base does the same. This belongs to FR-0020's project-specialised-files scope.
7. **Harness:** the brief's trailer named "Claude Opus 5". My commits use the session's attribution lines (`Claude Opus 5.5 (1M context)` plus the `Claude-Session` line).
