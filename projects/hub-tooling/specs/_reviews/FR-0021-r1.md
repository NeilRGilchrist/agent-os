It says so even when the optional `dispatch.py` import failed (`_dispatch is None`), in which case the FR-0008 lint is silently skipped. That includes unknown targets such as `FR-0998` from a DEC's `constrained_by`, which are not objects in the graph. It is the same behaviour the old gate had for `depends_on` errors, and it now reaches DEC/TR error text too.
